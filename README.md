# CIT4242 Advanced Programming Project

This repository will be used for my Advanced Programming course throughout the semester.

For this project, I plan to build a simple application that can be extended step by step as I learn new topics in the course. The application will start with a basic Java and Maven structure, and later I will add more features using Spring Boot, REST APIs, database persistence, testing, continuous integration, Docker, caching, and messaging.

My goal is to create a project that is easy to understand, easy to build, and easy for another developer to run on a different computer. I also want to practice using Git correctly by creating clear commits, working with branches, and using pull requests.

As the semester continues, this repository will be updated every week and will gradually become a complete application that demonstrates the programming and software engineering skills covered in the course.
